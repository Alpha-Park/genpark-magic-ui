# genpark-magic-ui

Generative design system builder.

Stop paying for closed SaaS apps. This is a terminal-native, open-source alternative to **Magic Patterns**.

Give your agent a concept, and it outputs production-ready Tailwind + Radix UI components, instantly generating functional Storybook previews on your local machine.

## Usage
```bash
openclaw use genpark-magic-ui
```
